# Aether-only native capture

This console STA target links the real immutable markup component and metrics reporter. It does not reference the GUI validator. Use the fixed capture CLI or the focal self-test through RunCapture.ps1, after independent source review and publication approval.

Interval A contains initial render and resource stabilization with no capture request or copy. The real PerfReporter is closed before B. B is a separate frame on the same host and immutable HTML snapshot. Its timing includes full diagnostic fallback, readback and Present. Encoding and independent System.Drawing decoding have separate timings. None is a pure GPU benchmark, FPS or comparison with Chromium.

Tracked resource completion means the real resolver Changed was applied to the host on its owner STA, not merely loader completion. Epoch changes reject stability. Resource failures do not become success: the existing non-base64 SVG policy is preserved, and requested failures produce exit 3 with an incomplete genuine raster. The PNG remains diagnostic until visual review. Fixed landmarks are content checks, not conformance or pixel parity.

The PNG writer takes only packed BGRA premultiplied bytes from the committed backend frame, explicitly converts to straight RGBA, and validates every pixel using an independent decoder. The swapchain is not a desktop screenshot. Present success does not prove a person saw the frame. Glyph fallback remains unverified and font parity is not evaluated.

Outputs are new per run, never overwritten. The external process wrapper enforces hard time limits and descendant monitoring; polling cannot prove absence of a transient process by itself. Static dependency/member-reference gates and no process-launch APIs in the executable supplement runtime module guards. Runtime and PNG results are NOT RUN until exact-SHA Windows CI completes; no browser is authorized by this route.
