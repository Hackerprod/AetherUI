# T1.8 — private typography evidence

Scope: retain evidence from the existing contextual cascade. This is **not** a font resolver, grouping authority, shaper, provider or renderer. No public C ABI, dependency, Actions workflow or original fixture changes.

## Storage and provenance

Accepted `font-family`, `font-style` and `letter-spacing` longhands retain their source tokens before legacy parsers project them into first-family/scalar/no-op values. The existing cascade selects the winner. Deferred values use the existing substitution pass; the evidence parser sees the substituted source before legacy parsing destroys distinctions. There is no second selector/cascade pass.

Each immutable node record owns a `TypographyRecord` bound to its exact revision generation, document identity, DOM input/structure/style epochs and sheet/cache epoch. The schema/registry profile version is 1. Revision freezing rejects mismatched sidecar metadata. Old snapshots retain their old evidence; they are not a current-document claim. Snapshot copying retains the immutable record rather than reconstructing it from public scalars.

Evidence fields distinguish known / unknown / unsupported. Known families preserve order, all names, escapes, and quoted names versus generic families. Names are not truncated to the public 64-byte slot. Simple style keywords and normal versus explicit absolute letter spacing remain distinct. Unsupported relative lengths and other forms are not fabricated as zero/normal. No declaration or an unprovable initial leaves unknown; absence does not invent a font default.

Per-field provenance retains a bounded accepted declaration source (at most 64 KiB), priority components and inheritance indication. Parsing limits are 64 KiB and 256 families; no truncated list is reported known.

## Coverage is deliberately incomplete

`coverage_complete` stays false even if all three fields are known. `coverage_gaps` bit 1 records the unrepresented typography/sheet pipeline. Bit 2 records matching discarded declarations: `font`, `all`, unrepresented typography longhands or rejected tracked longhands. That condition conservatively clears field evidence rather than claiming that discarded CSS had no effect. Unprocessed/external sheets, features, variations, font-face selection and many other typography inputs remain unproved. Known is evidence of the supported native cascade value, not proof of effective browser CSS or render readiness.

A changed evidence value/provenance/coverage produces layout/text-layout/paint impact even when legacy scalar storage is equivalent. The existing staged preparation transaction publishes style and sidecar together; allocation failures abort the candidate and preserve previous committed state.

## Limits

No new font provider calls, real shaping, glyph rasterization or original Flexbox render. Chromium comparison is NOT_RUN. The native text gate remains closed. The original fixture remains unchanged. Font-style angle syntax rejected by the existing parser is conservatively uncovered, never normal. Variable substitution failures conservatively yield unknown, because the resolver does not distinguish missing/cyclic values from budget exhaustion. Any invalid/unproved terminal in the inherited frozen custom-property scope conservatively makes deferred typography unknown, including successful fallback substitution: invalid terminals can have originated from an implementation limit. Rejected substituted values also remain unknown rather than claiming inherited normal/zero. CSS-wide values follow the existing native cascade and remain unknown whenever the initial value cannot be proven by this evidence layer.

## Validation

`tests/isolated_capture/run_t18_typography.sh BUILD_DIRECTORY` runs parser and real-runtime fixtures. Candidate result: 2,735 runtime checks, 371 preparation allocation-failure points; commit path required no allocations in the exercised transaction. Coverage includes cascade/important/order, inheritance, variables/fallbacks/budget failures, quoted/generic families, long names, no-op scalar invalidation, snapshots, epochs/cache, stale transaction and mixed metadata rejection. Parser limits/units/unsupported forms also pass.

Regression suites T1–T1.7 and H20/H21 passed during implementation. Final independent review and its clean build remain required before publication. The normal target has no synthetic issuer symbol. No real font rendering or Chromium comparison was executed.
