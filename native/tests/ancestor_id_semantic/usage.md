# Untimed public equivalence oracle

Run `python native/tests/ancestor_id_semantic/generate.py` after reviewing any public-header change. The generator fails on unsupported struct syntax and records the exact public-header hash plus every field in `field_manifest.json`. `fields.generated.h` explicitly reads 23 public struct types and the 15 payload arms of all 19 command tags. Pop tags have no payload. No padding, inactive union bytes, pointer addresses, unused fixed-string suffixes or approximate float comparisons are used. Dynamic arrays retain order and lengths; null and empty owned strings are distinguished. Float scalars are recorded exactly as their 32-bit value representation. Public stable node IDs are kept verbatim, not normalized away.

`page.generated.cpp` is an instrumented copy of `test_flexbox_page.cpp`; generation adds only the snapshot include and one export call after display-list readback. The original file and HTML are not edited. Snapshot export reads styles in DOM preorder, recording absent styles explicitly, then all public update styles (including styles not in the original DOM inventory), impacts and stable IDs, then every display command in command order. Every copied style and command is freed normally. Snapshots are outside engine stage timings, but **all timings from this diagnostic harness must be ignored**.

Build the baseline and candidate ordinary Release shared libraries first, then run from the repository root:

    python native/tests/ancestor_id_semantic/compare.py --baseline-lib BASE_BUILD/libaether_core.so --candidate-lib CANDIDATE_BUILD/libaether_core.so --output NEW_PRIVATE_EVIDENCE_DIRECTORY

The Python comparator also checks nine deliberate changes to copied records, including ordering, missing/extra records, nested array values and null strings. The runner creates the output directory exclusively, preserves all logs and captures binaries/source identities. It runs the generated sensitivity fixture, then each arm once at 1440×900, 768×900 and 390×900. It compares every semantic record, byte-identical geometry, original assertion counts, five semantic-case records and work counters. No benchmark population is created. The full fixture still has semantic assertions for only five of 403 cases; this comparison proves candidate/baseline equivalence, not correctness of every case or browser parity.

`sensitivity.generated.cpp` initializes one item in every dynamic nested array and changes each scalar, string and array count independently, requiring serialization to differ and restoring the copied value afterward. It exercises fields absent from the actual page too. The fixture creates plain public value objects, not engine mutations or ownership/media experiments. It can compile standalone with the public include directory and C++20; no core library is needed.
