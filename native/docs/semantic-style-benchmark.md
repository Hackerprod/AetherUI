implementation `ff0fd2cc95fbf017f604de9cd717c4aaeecac139`. Both include explicit
opacity inheritance. GCC 14.2.0, Release `-O3 -DNDEBUG -ffp-contract=off`;
identical standalone fixture v2 with two backgrounds, two text shadows, two box
shadows, two backdrop filters and three transforms in the rich case.

The following table preserves both runs and their dispersion rather than
selecting only the best sample. Raw per-sample CSV and summary JSON are retained
with the validation handoff. Shared-executor noise remains visible. See
[validation and limits](semantic-style-validation.md) for the allocation and
old-revision-retention diagnostics; these measurements do not imply a universal
speedup.
