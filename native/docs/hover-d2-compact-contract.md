# D2 compact publication and context contract (implementation plan)

The added compact publication API is staging-only. A base legacy map must carry a private factory-issued projection-source revision token that equals the transaction's retained base revision, including shared-owner authenticity and document identity. An arbitrary map, the same generation, matching element count, or zero visual impact does not prove coverage. Recovery or unknown lineage uses D1's complete staging API. Contextual override acceptance remains exact-revision and is unchanged.

A certified payload revision retains its compact semantic positions and its stable-order/base-revision identity certificate. These come from CertifiedRevisionDelta, not a new comparison of N leaves. The certificate does not retain a chain of old revisions. Metadata-only payload changes remain in the compact stream, even when their visual impact is zero. Structure/unknown coverage selects complete staging. The result separately reports completeness, semantic count and aggregate visual impact. Native patching consumes exactly this stream and reuses the immutable backing for no changes; a new lightweight map wrapper retains the current projection source and epochs. No-op is not inferred from a returned null handle or failure.

.NET uses persistent immutable dictionaries for projected styles and the native projected-style index. Changed paths are staged before commit; no-op preserves StyleMap and projected boxes. Affected live primary/paint boxes are enumerated through their identity indexes only after staging. Metadata-only native publication updates its native map and semantic consumers; transition observation requires an actual projected value difference and never starts from metadata alone. Existing D1 publication/reentrancy checks remain; its known native Observe/Tick atomicity gap remains explicitly out of scope.

The native context implementation uses immutable Patricia indexes (existing PersistentIndex representation) for static causes, active-transform causes, and effective membership. Each source has a retained lineage and membership serial; shared roots are exact equality certificates, not hashes. Static source changes are prepared with backing patches. Transform membership changes are separate from a future general TransitionSerial. Union updates diff source roots and compute final combined causes by authentic identity. A cause-only change reuses effective membership. Document, topology and map membership coverage are required; legacy/unknown coverage falls back to the same complete helper used by the oracle. Counts include context indexing performed during backing/transition mutation, not only PrepareTransitionContext.

All new exports will be in dedicated D2 blocks. Experimental native and managed routes remain default OFF. Tests enable the route explicitly. Candidate base is c577a1a; a merged C3c performance tree, if used, will be identified separately. No C3d code is imported.

Implementation boundaries:
- Full contextual maps carry the same private static cause snapshot from their exact StyleRevision; no backing materialization is needed for the certificate. Stable semantic deltas update the source index by token. Legacy arbitrary maps use their backing source or the complete fallback; they cannot claim publication-source provenance.
- Source indexes store declared causes before commit, including detached generated candidates. Only the effective union/full helper tests current attachment and eligibility. Unknown document/topology/style-tree coverage never reuses membership.
- Context allocation counters count attempted allocations for persistent nodes, snapshot/lineage owners and temporary full-build vectors, including failed attempts. They are not byte/GC counters. Source maintenance is counted where performed, including native transition Observe/Tick, and is not shifted outside measured intervals.
- With the native context option OFF, the complete helper runs at preparation and layout; incremental union, O(1) cache reuse and one-shot snapshot reuse are disabled. Representation/lifetime safety remains compiled. Managed delta opt-in remains internal and false by default.
- Managed LayoutResult/LayoutBox are live mutable projections under the existing API. Staging does not mutate them. Their publication assignments keep the existing contract; native retained frames/clones and all context owner snapshots are immutable.
