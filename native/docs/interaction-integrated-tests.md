# Private integrated interaction tests

`tests/test_interaction_integrated.cpp` links the native production object set except for `aether_interaction.cpp`, which is rebuilt with `AETHER_INTERACTION_TESTING`. Test hooks are not exported by the production DSO. The executable drives the public API; private hooks observe the instrumented ledger and inject quota/version/sequence boundaries only.

The 10,000-cycle test edits and renders both text/password inputs, backspaces and renders each, changes focus, activates the button every 100 cycles and resizes out/back. First 5,000 cycles exercise empty-to-one-scalar-to-empty; last 5,000 exercise 255-to-256-to-255 scalars. Four admitted runtime scalars vary across cycles. Exact expected final state_version is 70,407, frame sequence 50,303 and activation count 100. Per-operation assertions also check unchanged sequence on state transitions, exact sequence increments on dirty render and no activation replay. Each normalized cycle checks retained storage against the first eight cycles of its phase. Curves include total and each category's current/peak requested bytes.

Quota exhaustion uses the actual current instrumented charge, not an arbitrary memory reserve. Failed dispatch/render/resize must preserve public state, previous frame bytes, output result and live charge, then recover when the original limit is restored. UINT64_MAX state/sequence tests must not wrap. A second thread tests all eight session API groups, including destroy, without mutating the owner-thread state.

The OOM harness replaces scalar/array, aligned/unaligned and throwing/nothrow allocation pairs in this test executable only. Counts are measured, not assumed. Creation tests a declared partial selection: first 16, last 16 and 32 quantiles, deduplicated. This samples source/DOM/provider initialization without claiming exhaustive cold allocation coverage. Cold creation and warm creation may have different counts due inherited initialization. For dispatch, a fresh session is used for every index; render/resize reuse the unchanged session after failed attempts and recreate it after any coherent success. Every attempt records whether the selected allocation was reached, the observed count and outcome. Successful internal fallback is distinguished from an unreached allocation; neither is reported as an OOM failure. Final retries must succeed. Existing focal allocator/provider/parser OOM tests remain separate requirements.

The external `run_integrated_interaction.py` recipe records commands, source snapshot/hash and exit codes. `--mode stress`, `--mode oom`, `--mode count` isolate work; `--sanitized` uses ASan/UBSan; `--optimized` uses the isolated O2 object build with assertions and `-ffp-contract=off`. No fast-math. Before accepting optimized stress, compare all six public C11/example BGRA artifacts byte-for-byte with the O0 DSO. Interrupted O0 stress logs are partial, never full passes. LeakSanitizer is disabled in the ptrace environment and remains NOT_VALIDATED; ASan/UBSan diagnostics are not suppressed.

These tests measure **instrumented storage only** under G0-M1, not total process/session memory or RSS. Legacy DOM/style/layout allocations remain excluded. Test results do not independently declare G1, pixel QA, or platform coverage beyond the tested environment. No password plaintext is logged or exported.

## Verified final R2 + hoist run (Linux, 2026-11-18)

- O2 normal and O2 ASan/UBSan: **10,000 integrated cycles PASS each**, 100 activations, state version 70,407, sequence 50,303.
- Stable normalized live instrumented storage: 1,546,578 bytes in the short phase; 1,548,208 bytes in the 255/256-scalar phase. Final peak: 1,653,084 bytes. Category curves agree between normal and sanitized runs.
- O0 normal and O0 ASan/UBSan OOM: creation **63 sampled points of 740 warm allocations**, dispatch **123 reached failures**, render **375 reached failures plus 9 coherent fallback successes**, resize **413 reached failures**. No selected index was unreached in the final runs. Creation remains partial, not exhaustive cold-allocation coverage.
- Owner-thread, lowered quota rollback/retry and state/sequence exhaustion passed in all four final executables. Six public C11/example BGRA artifacts were byte-identical across normal O0, normal O2 and sanitized O2.
- `interaction-final-summary.json` links the four mode evidence files; each contains SHA256 for the executable, private ABI hook object, test source snapshot and logs, plus the four-build production DSO/object manifest. Earlier interrupted or pre-fractional runs are not substitutes for these final results.

LeakSanitizer: NOT_VALIDATED (ptrace). Other platforms: NOT_RUN. These results do not by themselves declare G1 or a total-memory bound.
